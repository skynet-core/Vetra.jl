# T017 — Documentation, gallery, and application recipes

Status: see [TASKS.md](../TASKS.md). Dependencies: T013. Priority: adoption.
Goal: help users discover a concrete application and reproduce it quickly.

## Inputs and scope

Build on README.md, docs/GETTING_STARTED.md, docs/tutorial.jl, docs/make_tutorial.jl,
examples/, and docs/Project.toml. Reuse existing tutorials/assets; avoid parallel
editable copies of examples. Create a locally buildable, browsable documentation
entry point with a visual gallery. Choose the smallest suitable docs tooling and
record its docs-only dependencies. Deployment belongs to T019.

## Acceptance criteria

- Navigation connects installation, beginner tutorial, API, capabilities,
  cookbook, and troubleshooting; generated previews have descriptions/alt text.
- Reproducible recipes cover candlesticks, sparklines, gauges, KPI cards, image
  annotations, a scientific diagram, dashboard thumbnails, and a social card.
  Several outputs may share one small script; reuse the existing OHLC project.
- Examples supply deterministic data, explicit font setup, output paths, and
  expected visual results. Asset licenses/provenance are recorded.
- Gallery links/images resolve in the built docs from a clean checkout; no
  undocumented local paths, runtime network calls, or hidden notebook state.
- Prefer recipes over a new chart framework. Update examples for T014–T016
  during release integration if those APIs become available after this task.

## Validation

Use the documentation commands in [shared validation](../docs/ROADMAP.md#shared-validation).
Document one exact docs-build command; execute every recipe and its independent
assertions, inspect generated images, and check links. Do not publish a site.

## Results and handoff

Status: done (2026-11-07).

### Tooling decision (D025)

No new docs framework. The cookbook is one Literate.jl source
(`docs/cookbook.jl`) built by `docs/make_cookbook.jl` — the same pattern as
the OHLC tutorial (D020) — emitting executed `COOKBOOK.md` +
`COOKBOOK.ipynb`. The gallery is a hand-written static
`docs/build/gallery.html` generated by ~30 lines in the build script.
`docs/INDEX.md` is the tracked browsable entry point (navigation table:
installation, beginner guide, tutorial, API, capabilities, cookbook,
gallery, troubleshooting). Generated output is gitignored under
`docs/build/`. Docs-only dependencies: Literate (already in docs env, D020);
no new package.

### Build command

```sh
julia --startup-file=no --project=docs docs/make_cookbook.jl
```

Prerequisites (once per checkout): `Pkg.develop(path=".")` +
`Pkg.instantiate()` in `docs/`, and `scripts/fetch_upstream.jl` for the
pinned fonts. The exact command is documented in `docs/INDEX.md` and added
to the roadmap's shared validation list. The recipes also run standalone:
`julia --startup-file=no --project=docs docs/cookbook.jl`
(≈7.7 s wall for all eight, including startup; all assertions pass).

All recipes: hardcoded data (no RNG, no network, no system fonts), explicit
font setup (Roboto-Regular / NotoSans from the pinned upstream fixtures,
Apache-licensed per NOTICE — the only font setup), explicit output paths
under `docs/build/cookbook/`, and a prose description of the expected visual
result. Two font notes recorded: `Inter-*.ttf` fixtures are CFF-outline and
raise `ArgumentError` by D015, so the cookbook uses glyf-outline
Roboto/NotoSans.

browsable artifact (D025).
